# ResumeForge AI 🚀

> **AI-Powered Resume Analyzer & Rebuilder**

ResumeForge AI is a modern SaaS-style web application that analyzes resumes, provides ATS-friendly insights, matches resumes with job descriptions, and rebuilds resumes into a cleaner, more professional format.

## ✨ Features

- 📄 Upload PDF and DOCX resumes
- 🤖 AI-powered resume analysis
- 🎯 ATS compatibility score
- 💼 Job Description matching
- 🔍 Missing keyword detection
- 📊 Circular animated score dashboard
- 📈 Resume insights & recommendations
- 📝 AI Resume Rebuilder
- ⚡ Side-by-side comparison
- 📥 Download rebuilt resume as PDF
- 🌙 Modern animated SaaS UI
- 📱 Fully responsive design
